Methodological Evaluation & Curse of Dimensionality

Mathematical rationale for underwriting policy standard

High-cardinality features such as OCCUPATION_TYPE (18 levels) and ORGANIZATION_TYPE (58 levels) induce severe data sparsity when transformed through binary One-Hot Encoding. This expands feature space dimensionality from 54 to over 1,480 columns, causing tree split dilution and catastrophic memory overhead.

check_circle Smoothed Bayes Formulation:
S_i = λ(n_i) * ȳ_i + (1 - λ(n_i)) * ȳ_global  |  λ(n_i) = n_i / (n_i + m)

With smoothing prior parameter m = 10, categories with negligible support are pulled gracefully toward the portfolio macro default prevalence (8.07%), eradicating target leakage and variance spikes.
